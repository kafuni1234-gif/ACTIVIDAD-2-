
# Proyecto de práctica con Git y GitHub

## 1. Descripción del proyecto

Este proyecto tiene como finalidad aplicar los conceptos básicos de Git y GitHub mediante la creación, modificación y documentación de archivos de texto (.txt).

A través de esta actividad se busca comprender el funcionamiento del control de versiones, registrar los cambios realizados y mantener un historial organizado del trabajo.

## 2. Objetivos

### Objetivo general

Aprender a utilizar Git y GitHub para gestionar versiones de archivos y documentar los cambios realizados durante el desarrollo de la actividad.

### Objetivos específicos

- Crear y administrar un repositorio en GitHub.
- Utilizar los comandos básicos de Git.
- Crear y modificar archivos de texto.
- Registrar cambios mediante commits.
- Utilizar mensajes de confirmación claros y descriptivos.
- Sincronizar los cambios con el repositorio remoto.
- Documentar el proceso de trabajo.

## 3. Herramientas utilizadas

- **Git:** sistema de control de versiones.
- **GitHub:** plataforma para alojar y administrar repositorios.
- **Bloc de notas:** editor de texto para modificar archivos.
- **Símbolo del sistema (CMD):** terminal para ejecutar comandos de Git.

## 4. Estructura del repositorio

El repositorio contiene los archivos de texto y la documentación desarrollados durante la actividad.

La estructura se organizará de acuerdo con los ejercicios y las instrucciones establecidas para el proyecto.

## 5. Comandos básicos de Git

| Comando | Descripción |
|---|---|
| `git --version` | Verifica la versión instalada de Git. |
| `git init` | Inicializa un repositorio local. |
| `git clone` | Copia un repositorio remoto. |
| `git status` | Muestra el estado de los archivos. |
| `git add` | Prepara los cambios para registrarlos. |
| `git commit` | Guarda los cambios en el historial. |
| `git log` | Muestra el historial de confirmaciones. |
| `git push` | Envía los cambios a GitHub. |
| `git pull` | Obtiene e integra cambios del repositorio remoto. |

## 6. Procedimiento

1. Instalar y configurar Git.
2. Crear o clonar el repositorio.
3. Crear y modificar archivos de texto.
4. Revisar los cambios con `git status`.
5. Preparar los archivos con `git add`.
6. Registrar los cambios con `git commit`.
7. Subir los cambios a GitHub con `git push`.
8. Documentar el proceso realizado.

## 7. Ejemplo de registro de cambios

```bash
git status
git add archivo.txt
git commit -m "Actualiza el archivo de texto"
git push
```

Nota: `archivo.txt` debe reemplazarse por el nombre real del archivo modificado.

## 8. Dificultades y soluciones

En esta sección se documentarán las dificultades presentadas durante la instalación, configuración y utilización de Git, junto con las soluciones aplicadas.

## 9. Resultados esperados

- Comprender el funcionamiento básico de Git y GitHub.
- Mantener un repositorio organizado.
- Registrar correctamente los cambios realizados.
- Crear un historial de versiones.
- Mejorar las habilidades de documentación y control de versiones.

## 10. Conclusión

Esta actividad permite desarrollar habilidades básicas en el manejo de Git y GitHub, comprendiendo la importancia del control de versiones, la organización de archivos y el registro de modificaciones. Asimismo, fortalece el uso de herramientas que facilitan la gestión y documentación de proyectos.
